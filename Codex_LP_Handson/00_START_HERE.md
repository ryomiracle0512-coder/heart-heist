# Codex LP Handson

## このフォルダで行うこと

Codexの導入が終わっている参加者向けに、60分で「自分の活動紹介LP」を作るハンズオン教材です。

この回では、HTMLやCSSの文法を暗記するのではなく、次の開発サイクルを体験します。

1. 自分の要望を整理する
2. Codexに設計させる
3. Codexに実装させる
4. ブラウザで確認する
5. 自分好みに改善する
6. Codexに最終確認させる

## 最初に行う操作

1. ZIPファイルを解凍します。
2. ChatGPTデスクトップアプリでCodexを開きます。
3. **`01_WORKSPACE`フォルダだけ**をCodexで開きます。
4. `LP_BRIEF.md`へ自分の情報を入力します。
5. `PROMPTS.md`のSTEP 1から順番にCodexへ貼り付けます。

> ZIPファイルの中を直接編集しないでください。必ず解凍してから使用してください。

## 困ったとき

90秒ほど確認しても解決しない場合は、全体進行を止めずに`02_RECOVERY`の対応フォルダから再開してください。

- 設計で止まった：`STEP1_PLAN_READY`
- LP生成で止まった：`STEP2_LP_READY`
- デザイン変更で止まった：`STEP3_CUSTOMIZED`

復旧用フォルダには架空のサンプル情報が入っています。自分の情報へ差し替えてから使用してください。
