# STEP 1｜LPの設計を作る

**所要時間：5〜7分**  
**完了の目印：`LP_PLAN.md`が作成される**

```text
AGENTS.mdとLP_BRIEF.mdを確認してください。

今回制作する活動紹介LPについて、
まだコードを書かずに設計してください。

以下を整理してください。

1. LPの目的
2. 想定する閲覧者
3. 閲覧者に最初に伝えるメッセージ
4. ページ全体のセクション構成
5. 各セクションに掲載する内容
6. 最も重要なCTA
7. デザインの方向性
8. PCとスマートフォンでの表示方針
9. 完成条件

LP_BRIEF.mdにない実績や数字は追加しないでください。

設計結果をLP_PLAN.mdへ保存し、
初心者向けに概要を説明してください。
```

# STEP 2｜最初のLPを実装する

**所要時間：10〜14分**  
**完了の目印：`index.html`、`styles.css`、`script.js`が作成される**

```text
AGENTS.md、LP_BRIEF.md、LP_PLAN.mdを確認し、
設計内容に沿って活動紹介LPを実装してください。

以下の3ファイルに分けてください。

・index.html
・styles.css
・script.js

ページには、情報がある範囲で以下を含めてください。

・ファーストビュー
・自己紹介
・強み
・現在行っていること
・提供できること
・経験または取り組み
・大切にしていること
・問い合わせ導線
・フッター

条件：

・LP_BRIEF.mdにない実績や数字を作らない
・HTML、CSS、JavaScriptだけで動作させる
・外部APIを使用しない
・外部ライブラリを使用しない
・index.htmlを直接開くだけで表示できるようにする
・PCとスマートフォンの両方に対応する
・横スクロールを発生させない
・読みやすさを最優先する
・プロフィール画像がない場合は、assets/profile-placeholder.svgを使用する
・ボタンとナビゲーションを操作できるようにする
・控えめなアニメーションを付けてよい

実装後は、
作成したファイルと確認内容を報告してください。
```

実装後、`index.html`をダブルクリックしてブラウザで確認してください。

# STEP 3｜自分好みに改善する

**所要時間：7〜9分**  
**完了の目印：ブラウザを再読み込みすると見た目または機能が変わる**

## デザインを1つ選ぶ

- A：Codex研究ラボ風 — 青、紫、宇宙、ネオン、未来感
- B：ミニマル風 — 白、大きな余白、大きな文字
- C：SaaS企業風 — 信頼感、カード、整理された情報
- D：高級サービス風 — 黒、白、ゴールド、重厚感
- E：クリエイター風 — 明るい色、柔らかい形、親しみやすさ

## 追加機能を1つ選ぶ

- 1：ダークモード切り替え
- 2：FAQの開閉
- 3：固定表示の問い合わせボタン
- 4：経歴タイムライン
- 5：スクロール時の表示アニメーション

下記の`A`と`3`を、自分が選んだ内容へ書き換えてください。

```text
現在のLPに掲載されている
名前、経歴、実績、連絡先は変更せず、
デザインと使いやすさを改善してください。

デザインは、
「A：Codex研究ラボ風」
を選択します。

追加機能は、
「3：固定表示の問い合わせボタン」
を選択します。

特に以下を改善してください。

・ファーストビュー
・見出しの読みやすさ
・セクション間の余白
・強みを示すカード
・問い合わせボタン
・スマートフォン表示

既存機能を壊さず、
必要なファイルだけを修正してください。

修正後は、
どこを変更したか報告してください。
```

修正後、ブラウザを再読み込みします。

- Windows：`Ctrl + R`
- Mac：`Command + R`

# STEP 4｜最終確認と修正

**所要時間：4〜6分**  
**完了の目印：Codexが確認結果と修正内容を報告する**

```text
完成した活動紹介LPを最終確認してください。

以下を確認してください。

・LP_BRIEF.mdの内容と一致している
・書かれていない実績や数字を追加していない
・名前、肩書き、連絡先が正しい
・ファーストビューで人物像が伝わる
・スマートフォンで横スクロールが出ない
・文字が小さすぎない
・画像が崩れていない
・ボタンとリンクが動作する
・HTML、CSS、JavaScriptに不整合がない
・JavaScriptエラーがない
・キーボード操作時にフォーカス位置が分かる
・動きを減らす設定が考慮されている

問題がある場合は修正してください。

最後に、

1. 確認した項目
2. 発見した問題
3. 修正した内容
4. 最終確認結果

を報告してください。
```

# 追加で使える短いプロンプト

## 文章を短くする

```text
掲載情報の事実は変えず、
各セクションの文章を20％ほど短くしてください。
読みやすさと意味の正確さを優先してください。
```

## ファーストビューを改善する

```text
LP_BRIEF.mdの事実だけを使い、
ファーストビューで「誰に、何を提供する人か」が
5秒以内に伝わるよう改善してください。
```

## スマホ表示だけ直す

```text
PC表示の雰囲気は維持したまま、
320px〜480px幅での表示だけを重点的に確認し、
文字切れ、横スクロール、余白、ボタン幅を修正してください。
```

## 色だけ変更する

```text
文章、レイアウト、機能は変更せず、
配色だけを以下の方向へ変更してください。

希望する配色：ここに入力
```
