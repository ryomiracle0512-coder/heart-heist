# Prompt 02 — Harbor Greybox

```text
Implement Milestone 2 in docs/ACCEPTANCE.md using editable procedural geometry.

Build one compact night harbor with the following connected spaces: salvage ship spawn, quay, main yard, warehouse floor, raised control room, heart chamber, maintenance side route, and cargo exit. The player should see the grounded ship at spawn and glimpse the heart or its energy signature within the first minute.

Design the spaces around three overlapping routes:
- a direct combat route through the yard;
- a stealth route through cover, a maintenance opening, and the control room;
- a trade route that visits a dock fixer and a contraband crate near the quay.

Add temporary signs, light colors, and landmark shapes so a new player can orient without a minimap. Include useful cover, two vertical shortcuts, one locked door, one powered shutter, and a transport-safe route wide enough for the heart frame.

Add objective text only for the immediate goal. Avoid waypoint spam. Use authored level data rather than scattering mission rules through rendering components.

Run the player through all spaces, inspect collision and camera behavior, check for stuck points, capture screenshots from spawn, the yard, the heart chamber, and the ship, and update docs/STATUS.md. Do not start final art. Stop when Milestone 2 passes.
```
