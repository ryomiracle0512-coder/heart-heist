# HEART HEIST 実装・検証レポート

作成日：2026年9月14日 ／ 対象：PCブラウザ版 0.1.0

## 結果

港へ潜入し、浮遊心臓を奪い、廃船へ運び、接続して空へ脱出する一連のゲームを実装しました。戦闘・潜入・取引と、それらを組み合わせた混合ルートは、開始地点からの自動通しプレイでクリアを確認しています。検証した経路に進行不能の不具合は残っていません。

`prompts/00_MASTER.md` と設計資料を確認し、01〜07の順で実装・検証しました。08のモバイル仕様は確認済みですが、07の「Do not begin the mobile port in this task.」に従い、今回の実装はPC版までです。未確認の受け入れ条件は下記に明示しています。

ソースの提出先：[GitHub heart-heist](https://github.com/ryomiracle0512-coder/heart-heist)。PC基準のソースコミットは [PC_BASELINE.json](PC_BASELINE.json) に記録します。GitHubへの登録と、ゲームのWeb公開は別であり、今回は公開ホスティングを行っていません。

### 性能・容量

- ローカルChrome、開発ビルド、1920×1080、中画質（描画倍率0.85）、12サンプル：平均60 FPS、最低サンプル58 FPS。[測定データ](evidence/performance-presentation.json)
- 本番アセット合計：4,628,707 bytes。gzip換算：2,098,568 bytes。20MB目標内です。実際の転送量は配信サーバーの圧縮設定に依存します。[容量・ハッシュ一覧](evidence/production-budget.json)
- 動画確認で深淵を海面が覆う問題を発見し、海面の開口、内壁、動く光を修正しました。[修正後スクリーンショット](evidence/07-abyss.png)

### 未確認・制約

初見の第三者が2分で目的を理解できるか、初回20〜30分の体験になるか、独立した人間によるプレイ感想は未確認です。自動プレイ時間を人間のプレイ時間とは見なしません。幅広いPC・スマートフォンの実機性能、タッチ操作、熱・メモリ、PWA・オフライン配信も未検証です。GitHub Actionsの設定は同梱していますが、リモートCIの成功は本レポートの検証結果に含めません。

警備員の経路探索とアートはこの縦切り版に合わせた簡素な実装です。心臓を抱えたまま警備員の前をゆっくり通ると倒されるため、遮蔽物と牽引への切り替えが必要です。

## 実際に遊ぶ

### 起動

この作業で起動したプレビューは [http://127.0.0.1:4173/](http://127.0.0.1:4173/) です。同じMacでサーバーが動いている間に使えます。「潜入を開始」を押し、視点が動かない場合はゲーム画面をクリックしてください。Escでマウスを解放できます。

サーバーを終了した後は、ターミナルで次を実行します。初回の依存関係インストールにはネット接続が必要です。

```sh
cd /Users/nakamurasatoshi/Documents/GitHub/heart-heist
npm ci
npm run dev
```

ターミナルに表示されるURLを開いてください。`index.html` のダブルクリックでは動きません。本番版を再確認するときは `npm run build` の後に `npm run preview` を実行します。

### 最初の1回：取引ルート

1. 開始地点から左側（西）の岸壁へ進み、仲介人「ナギ」に近づきます。Eで話しかけ、「箱を探してくる」を選びます。
2. 岸壁を北へ進み、黄色い「CONTRABAND」の密輸箱をEで回収します。
3. ナギへ戻り、Eで会話して「箱を渡す」を選びます。入場コードは3分、警備の陽動は2分なので、受け取ったら倉庫へ向かいます。
4. 倉庫正面のシャッターに近づいてE。奥の心臓室の扉もEで開け、青く光る心臓を探します。
5. 心臓に近づいてEで取り外し、もう一度Eで持ち上げます。停電で正面シャッターが閉じ、東側の貨物出口が開きます。
6. 貨物出口から屋外へ出て、建物の東側を南へ回り、南西の廃船へ戻ります。抱えると遅くなります。Tで牽引すると速くなりますが音が出ます。角で引っかかったら少し戻って持ち上げ直してください。
7. 船の接続口に近づいてEで装着し、もう一度Eで点火します。Spaceで高度10m以上へ上昇し、Wとマウスで北の光のゲートへ向かうとクリアです。Xで下降、Shiftでブーストできます。

### よく使う操作

| 操作 | キー |
|---|---|
| 移動／視点 | WASD／マウス |
| 走る／しゃがむ／ジャンプ | Shift／C長押し／Space |
| 調べる・会話・拾う・装着 | E |
| 射撃／近接／装填 | 左クリック／F／R |
| 牽引の開始・解除／心臓を降ろす | T／Q |
| 一時停止・マウス解放 | Esc |
| 船の上昇／下降／ブースト | Space／X／Shift |

心臓を抱えている間は攻撃できません。画面の目的・警報・操作表示を確認してください。再読み込み後は「続きから」でチェックポイントを再開できます。音量・視点感度・画質・カメラの揺れは「操作と設定」から変更できます。

2回目は、西側の回路と整備口、制御室のカードを使う潜入、または正面を突破し制御端末を使う戦闘を試せます。結果画面の「別の方法でもう一度」から新規プレイできます。
