# 2026-09-21 — マウスなし・可読性・スマホの設計変更

## 依頼と対象

ユーザーの設計変更依頼。ENGINE/UIの仕様とレビュー用見本を作成。提供されたAIゲーム開発プレイブックを参考に、現行ソースと番号順資料を照合した。ゲーム実装・新規アート・PWA配信・外部有料サービスは今回の成果物に含まない。

## 仮説と変更

- キーボード視点と射撃、pointer lockの任意化によりマウスなしでゲームの全行動に到達できる設計にする。
- タッチの射撃＋ドラッグと固定位置の文脈ボタンにより、3本以上の指を要求しない設計にする。
- 不透明なHUD背景、本文16px、48px以上のボタン、目的の短文化で小画面の可読性を上げる。
- GAME_DESIGN / TECH_SPEC / MOBILE_PORT / ACCEPTANCEを更新。詳細はACCESSIBLE_PLAY_DESIGN、操作見本はdesign/control-preview.html。

## 検証

- ソース確認：input/App/MissionHUD/style/Scene/store/interactables/combat。実装と設計を区別して記録した。
- レビュー用Chrome：3レイアウト×4場面×2文字サイズ×左右配置＝48組合せ。初回18組合せでHUD領域の重なりを検出。警告位置と小画面の対象ラベル位置を修正。
- 再検査：48/48で指定領域の重なり・はみ出し・小さすぎるボタンの検出なし。ページ例外0。補助一覧の選択・Escapeによる閉じる操作を確認。5枚の画像を保存し、探索・運搬の画像を目視確認。
- `git diff --check`。ゲーム本体のソース・依存関係・旧基準コミットは変更していないため、今回はゲームのbuild/unit/通しプレイは再実行しない。
- これは配置見本の検証。キーボードだけのゲームクリア、タッチだけのクリア、照準補助、設定移行、PWA、スマホFPS・入力遅延・発熱は未実装／未検証。
