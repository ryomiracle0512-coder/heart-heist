# HEART HEIST スマホ版の遊び方

更新：2026-09-22。ゲーム本体にタッチ操作を実装したオンラインのブラウザ版です。

- ゲーム：[HEART HEIST](https://heart-heist-browser.ryoakg.chatgpt.site)
- スマホで読む説明書：[遊び方・攻略](https://heart-heist-browser.ryoakg.chatgpt.site/help.html)

ログイン不要の公開版です。URLを開くだけで遊べます。Macを起動しておく必要はありません。初回・再読み込みにはインターネット接続が必要です。

## 開始

1. SafariまたはChromeでURLを開き、スマホを横にします。
2. 操作方法を「タッチ（スマホ）」にして「潜入を開始」。
3. 左の丸いスティックで移動、右側の空いている場所をなぞって視点移動。
4. 対象へ近づくと水色のボタンが「話す」「開ける」「心臓を持つ」などに変わります。

## 操作

| 操作 | 方法 |
|---|---|
| 移動 | 左スティック。離すと止まる |
| 見回す | 右側をドラッグ |
| 射撃・照準 | 「撃つ」を押す。押したままドラッグ可能 |
| 調べる・話す・拾う・接続 | 水色のボタン |
| 走る・しゃがむ | 各ボタンをタップして切り替え |
| 装填・近接・牽引の解除・降ろす | 「ほかの操作」から選ぶ。選択中は一時停止 |
| 船の上昇・下降 | 各ボタンを押す。離すと高度を維持 |
| 船の加速 | 「加速」でON/OFF。再充填あり |
| 設定・一時停止 | 右上のⅡ。再開は「港に戻る」 |

左利き配置、大きい文字、視点感度、音量、画質は「操作と設定」で変更できます。スマホでは「軽量」を推奨します。

## 取引ルートの攻略

1. 開始地点から西側の岸壁へ行き、仲介人ナギと話す。「箱を探してくる」を選ぶ。
2. 岸壁の北の黄色いCONTRABAND箱を拾い、ナギへ戻って渡す。
3. コードが有効な3分以内に倉庫正面と心臓室を開ける。陽動は2分間。
4. 青い心臓の「ケーブルを外す」→「心臓を持つ」。停電で正面が閉じる。
5. 東の貨物出口から外へ出る。建物の東側を南へ回り、南西の船へ戻る。
6. 船で「心臓を接続する」→「点火」。
7. 「上昇」で高度10m以上へ。北の光のゲートへ操縦するとクリア。

心臓を抱えると遅くなり、攻撃できません。「牽引へ」は速い代わりに音を出します。角で引っかかったら少し戻るか、解除して持ち直します。

## 保存・制限

重要な進行と一時停止時に保存し、再読み込み後は「続きから」で再開します。保存は端末・ブラウザごとで、端末間同期はありません。縦向き・別アプリへ移動すると停止し、横に戻した後に手動再開します。

Chromeのタッチエミュレーションで4ルート完走、2指同時入力、保存・復帰、小画面の表示を検証済みです。iPhone SafariやAndroid実機の性能・発熱・操作感は未検証で、全機種対応を保証する段階ではありません。PWAのオフライン保存・ネイティブアプリは実装していません。
