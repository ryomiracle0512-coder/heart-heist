# 操作・UI設計見本

`control-preview.html` をブラウザで開くと、端末・探索/戦闘/運搬/飛行・左右利き・文字サイズを切り替えられます。補助一覧はクリック/キーボードで開閉できます。描画した港は模式的な背景で、実ゲームのスクリーンショットではありません。スティック・戦闘・照準・3D物理はこの見本では動きません。

仕様は [ACCESSIBLE_PLAY_DESIGN.md](../ACCESSIBLE_PLAY_DESIGN.md) を参照してください。

## 再検証

リポジトリルートで依存関係を `npm ci` で導入し、Google Chromeがある環境で行います。

```sh
python3 -m http.server 4180 --bind 127.0.0.1 --directory docs
# 別のターミナルから
node docs/design/check-layout.cjs
```

`HEIST_DESIGN_URL` で検査URLを変更できます。48組合せの領域重複・はみ出し・ボタンの最小サイズ、補助一覧・Escape、ブラウザ例外を確認し、結果JSONと5枚の代表画像を `evidence/` に保存します。失敗時は終了コード1です。スクリーン全領域のピクセル比較や文字の全組合せ、実機のタッチ操作の検査ではありません。

## 結果

2026-09-21：最初の検査で大きい文字の状態表示と警告、最小横画面の目的と対象表示の重なりを発見。配置修正後、48組合せで検出された重なり・はみ出し・48px未満のボタンは0。ブラウザ例外0。運搬と探索の画像を目視確認しました。

画像・JSONは設計見本に対する証拠です。PCゲームの旧検証記録やスマホ実機の検証として扱わないでください。
