# HEART HEIST — 世界の心臓を盗め

夜の工業港から浮遊心臓を奪い、廃船へ接続して空へ脱出する、一人用のブラウザ3Dゲームです。戦闘・潜入・取引は同じ地形、扉、電源、心臓を共有します。プレイヤーの行動は個別の痕跡として記録され、複数の方法を組み合わせられます。

## スマホから遊ぶ

- [ゲームを開く](https://heart-heist-browser.ryoakg.chatgpt.site)
- [スマホ向けの説明書・攻略](https://heart-heist-browser.ryoakg.chatgpt.site/help.html)

横向きにして「タッチ（スマホ）」で開始。左スティックで移動、右側をなぞって視点、水色のボタンで話す・拾う・接続します。インストールやログインなしで、URLを開いて遊べます。

2026-09-22にゲーム本体へタッチ操作・キーボード視点・読みやすいHUDを実装しました。[操作ガイド](docs/MOBILE_PLAY_GUIDE.md)と[検証記録](docs/devlog/2026-09-22.md)を参照してください。スマホ実機の性能・全機種対応は未検証です。PWA/オフライン対応は含みません。

## 起動

Node.js 22以上とnpm、WebGL2が使えるPCブラウザを使用してください。

```sh
npm ci
npm run dev
```

表示されたローカルURLを開き、「潜入を開始」をクリックします。選んだ操作方法で開始し、音声を有効にします。マウス固定は「マウス＋キーボード」の場合だけです。`Esc` で必ずマウスを解放して一時停止できます。

```sh
npm run build       # TypeScript確認と本番用distの生成
npm run preview     # 本番ビルドをローカルで確認
npm test            # 決定的なゲームロジックの単体テスト
npm run lint        # ESLint
npm run test:e2e     # Chromeでブラウザテスト
```

ローカルのE2Eテストはインストール済みGoogle Chromeを使用します。録画には `npx playwright install ffmpeg` が必要です。本番の `dist/` は静的Webサーバーで配信できます。`index.html` を直接ダブルクリックする形式ではありません。GitHubへのソース追加だけではWebサイトは公開されません。

## 操作

| 操作 | キー |
|---|---|
| 移動 | W / A / S / D |
| 視点・照準 | 矢印キー、またはマウスモードでマウス |
| 走る | Shift |
| しゃがむ | C（キーボード専用は切替、マウス併用は押下） |
| ジャンプ | Space |
| 調べる・会話・拾う・接続 | E |
| 射撃 | J、またはマウスモードで左クリック |
| 近接攻撃 | F |
| 装填 | R |
| 牽引開始・解除 | T |
| 心臓を降ろす | Q |
| 一時停止・マウス解放 | Esc |
| 船の点火 | 接続後に E |
| 船の操縦 | WASD + マウス |
| 船の上昇 / 下降 | Space / X |
| 船のブースト | Shift（再充填あり） |
| 開発用表示 | F3（開発ビルドのみ） |

音量、感度、カメラの揺れ、画質は「操作と設定」から変更できます。非表示タブとフォーカス喪失時は安全に停止します。

## 三つの方法

- **戦闘**：正面を突破し、警備員を排除または牽制。制御室の端末から心臓室を開けます。
- **潜入**：西側の回路を切って整備口を開け、制御室にある監督者のカードを使います。遮蔽物としゃがみ移動が役立ちます。
- **取引**：西の岸壁の仲介人・ナギに会い、岸壁北の密輸箱を届けます。コードは3分間、陽動は2分間です。

心臓を外すと、貨物出口が開き、正面シャッターが閉じます。東側の貨物出口から南西の廃船へ戻ってください。抱えて運ぶと攻撃できず、牽引は速い代わりに音を出します。狭い角で引っかかったら戻って持ち上げるか、いったん解除して付け直します。接続後は点火し、高度10m以上で港の北の光のゲートへ向かいます。

## 保存と再開

重要な電源・所持品・心臓の状態変更と一時停止時に、ローカルストレージへチェックポイントを保存します。アカウントやサーバー送信はありません。再読み込み後は「続きから」を選びます。セーブスキーマはバージョン1。破損・旧バージョンのデータには新規開始を案内します。保存が禁止されている環境でも、そのタブでのプレイは続行できます。

React、TypeScript、Vite、React Three Fiber、drei、Rapier、Zustand、Howlerを使用。入力変換、ミッション、戦闘、視界、運搬、保存を分離しています。

- [日本語の実装・検証レポートと初回攻略](docs/IMPLEMENTATION_REPORT.md)

- `docs/RELEASE_CHECKLIST.md`：リリース判定と未確認項目

## 素材・クレジット

港、船、心臓、警備員、武器はオリジナルの手続き生成ジオメトリ。看板、照明用テクスチャ、環境マップはローカルCanvasで生成しています。音声は `scripts/generate_audio.py` による決定的な合成音です。外部ゲームのキャラクター、ロゴ、モデル、録音は使用していません。生成素材のメタデータとCC0宣言は `src/assets/generated/` にあります。依存ライブラリのライセンスは各パッケージに従います。

## 既知の制約

PCブラウザ向けの手続き生成アートによる縦切り版です。独立した人間による初見プレイ、20〜30分という初回プレイ時間の目標、幅広いPC性能は別途検証が必要です。自動テストの所要時間は通常のプレイ時間ではありません。

スマートフォン向けタッチUIを追加しました。PWA・ネイティブパッケージは未実装です。`07_FINAL_QA.md` のPC基準版の確認と、`08_MOBILE_PORT.md` に必要な実機検証を分けて扱います。現時点ではスマートフォン対応を保証しません。
